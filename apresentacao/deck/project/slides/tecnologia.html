Sem Docker, sem compilação nativa: instala, roda e serve site e API juntos.

Stack escolhida para uma equipe de 3 pessoas: Node.js 22 com Express 5 e TypeScript, banco SQLite nativo do Node (node:sqlite) em modo WAL, que atende com folga milhares de alunos no piloto, e frontend React 19 com Vite. Tempo real com Server-Sent Events. Senhas com scrypt, tokens JWT, entrada validada com Zod, SQL parametrizado, limite de tentativas de login e log de auditoria.
